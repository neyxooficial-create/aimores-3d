Como usar

Mouse: arraste com o botão esquerdo para mover o mapa, direito para girar/inclinar, rodinha para zoom. Duplo clique leva a câmera até o nível da rua.
Celular: 1 dedo arrasta o mapa (ou gira, se você trocar no botão “1 dedo”), 2 dedos fazem pinça para zoom e giram/inclinam. Em ⚙ Opções dá para mudar a qualidade e o horário.

Horário: o relógio começa no horário de Brasília. Use a barra para escolher a hora ou ▶ para o tempo passar. Ao anoitecer (por volta das 18h) os postes acendem, as janelas e os faróis dos carros ligam; de manhã (por volta das 5h30) os postes apagam.

Marcadores: no painel da direita crie uma categoria (cor + nome, ex.: verde = "ferreiro") e, se quiser, a quantidade máxima. Selecione a categoria, clique em Colocar e clique no mapa. Use Mover para arrastar. Clique num marcador para renomear, trocar de categoria, anotar ou apagar. Tudo fica salvo neste navegador; use Exportar/Importar para levar para outro aparelho.
